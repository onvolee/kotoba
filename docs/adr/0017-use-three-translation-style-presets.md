# Use three translation style presets

Kotoba will ship three first-version translation style presets: `Faithful`, `Natural`, and `Polished`. These presets tune tone and fluency, but they do not override the shared hard constraints to preserve Markdown or plain text format and leave code, URLs, file paths, commands, package names, API names, variables, and similar technical tokens untranslated. Full custom prompt editing remains out of scope for the first version.
