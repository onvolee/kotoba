# Use Tailwind CSS, shadcn/ui, and lucide-react for the workspace UI

Kotoba will build its extension-owned workspace UI with Tailwind CSS, shadcn/ui, and lucide-react. The workspace needs standard application controls such as buttons, selects, dialogs, drawers, text areas, toasts, and icon buttons, and shadcn/ui provides editable source-level components without committing the product to a heavier design system. We will avoid MUI or Ant Design in the first version because their visual defaults and package surface are heavier than this focused extension workspace needs.
